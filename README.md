## Что сделано

1. **Хранилище.** RustFS 1.0.1 в Docker на 4 папках-дисках (erasure coding 2+2). Датасет `it_vacancies_2024.csv`
   лежит в бакете `hh-lake` под ключом `raw/it_vacancies_2024.csv`. После загрузки SHA-256 объекта сверяется с исходным файлом.
2. **Свой MapReduce** (`lab/mapreduce.py`):
   - мастер читает объект из S3 чанками по 32 МиБ (Range GET);
   - граница чанка выравнивается по концу CSV-записи с учётом кавычек;
   - мапперы работают в отдельных процессах: фильтруют вариант, нормализуют навыки, порождают сочетания k = 1, 2, 3, сворачивают их combiner'ом и раскладывают по 4 редьюсерам через crc32;
   - редьюсеры складывают частоты;
   - отказ маппера (`os._exit(137)`) обрабатывается так: пул процессов пересоздаётся, потерянные задачи перезапускаются.
3. **DuckDB** (`lab/duck.py`) считает то же самое одним SQL-запросом по объекту в S3 через `httpfs`. Условие варианта в SQL написано отдельно от Python.
4. **Сверка** (`lab/verify.py`) сравнивает все ключи и частоты k = 1, 2, 3, а также набор отобранных вакансий. Рост числа сочетаний объясняется через Σ C(n, k) (`lab/growth.py`).
5. **Зарплаты** (`lab/salary.py`). Прибавка пары равна медиане пары минус медиана её более частого навыка. Для тройки база — самая частая пара внутри тройки.
6. **Регионы** (`lab/regions.py`): Москва, Санкт-Петербург и третий по числу вакансий регион.
7. **Профилирование** (`lab/profile.py`): каждый способ запускается 3 раза, перед каждым запуском RustFS перезапускается. Замеряются время, CPU и пик RSS всего дерева процессов.
8. **Бонус.** Сравнение «до» и «после»:
   - наивный MapReduce против версии с pyarrow, combiner и параллельными мапперами;
   - DuckDB по CSV против DuckDB по колоночной копии в Parquet.

Результаты k = 1, 2, 3 лежат в `results/mapreduce/` и `results/duckdb/` (и в бакете `hh-lake/results/...`).

## Как запустить

Нужны Docker Desktop и файл `dataset/it_vacancies_2024.csv`. Все вычисления идут в контейнере с Python и читают данные только из S3. Сам контейнер локальный файл вообще не видит.

```bash
bash scripts/00_check.sh        # проверка, сборка образа с python/duckdb/pyarrow
bash scripts/01_storage.sh      # rustfs + бакет hh-lake + загрузка и сверка sha256
bash scripts/02_mapreduce.sh    # свой mapreduce (оптимизированный и наивный)
bash scripts/03_failure.sh      # отказ маппера и перезапуск
bash scripts/04_duckdb.sh       # тот же подсчёт в duckdb
bash scripts/05_verify.sh       # сверка и рост числа сочетаний
bash scripts/06_salary.sh       # влияние пар и троек на зарплату
bash scripts/07_regions.sh      # три региона
bash scripts/08_profile.sh      # parquet-бонус и профилирование (3 запуска каждого способа)
bash scripts/09_report.sh       # сборка pdf-отчёта
```
